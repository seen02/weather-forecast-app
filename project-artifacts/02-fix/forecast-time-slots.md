# 5일 예보 시간 표시 수정

## 수정 배경

5일 예보에서 날짜를 펼쳤을 때 시간 목록이 `12:00am`, `03:00am`, `06:00am`, `09:00am`, `12:00pm`, `03:00pm`, `06:00pm`처럼 표시되는 문제가 있었다.

원인은 예보 데이터를 날짜별로 묶은 뒤 앞에서 7개를 단순히 자르는 방식이었다. 이 때문에 `00:00` 예보가 포함되고, 필요한 `21:00` 예보가 빠졌다. 또한 오후 시간은 `03:00pm`처럼 12시간제로 표시되어 시안의 `15:00pm`, `18:00pm`, `21:00pm` 형식과 맞지 않았다.

## 수정 내용

- `utils/forecast.js`에 표시 대상 시간을 `[3, 6, 9, 12, 15, 18, 21]`로 고정했다.
- 날짜별 예보 목록에서 `00:00`은 제외하고, `03:00`부터 `21:00`까지 순서대로 표시하도록 변경했다.
- 시간 포맷을 `03:00am`, `06:00am`, `09:00am`, `12:00pm`, `15:00pm`, `18:00pm`, `21:00pm` 형식으로 맞췄다.
- Jest 테스트에 시간 필터링과 포맷팅 검증을 추가했다.

## 영향 범위

- `utils/forecast.js`
- `__tests__/utils/forecast.test.js`

## 확인 기준

예보 날짜를 펼쳤을 때 시간 목록이 아래 순서로 표시되어야 한다.

```txt
03:00am
06:00am
09:00am
12:00pm
15:00pm
18:00pm
21:00pm
```
